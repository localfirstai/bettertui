title: Theming

BetterTUI uses CSS variables for theming. Dark mode and custom palettes are built in.

## Default Theme

```css
:root {
  --color-primary: #6366f1;
  --color-accent: #06b6d4;
  --color-success: #10b981;
  --color-warning: #f59e0b;
  --color-error: #ef4444;
  --color-text: #0f172a;
  --color-text-muted: #475569;
  --color-bg: #ffffff;
  --color-bg-muted: #f8fafc;
  --color-border: #e2e8f0;
}
```

## Custom Theme

```css
:root {
  --color-primary: #8b5cf6;
  --color-accent: #ec4899;
  --color-bg: #0f172a;
  --color-text: #f8fafc;
}
```

## Dark Mode

Dark mode is automatic based on terminal preferences, or toggle manually:

```tsx
import { useTheme } from '@bettertui/react';

function ThemeToggle() {
  const { theme, toggleTheme } = useTheme();

  return (
    <Button onPress={toggleTheme}>
      Current: {theme}
    </Button>
  );
}
```

## Preset Themes

```tsx
import { ThemeProvider } from '@bettertui/react';
import { draculaTheme } from '@bettertui/themes';

function App() {
  return (
    <ThemeProvider theme={draculaTheme}>
      <MyApp />
    </ThemeProvider>
  );
}
```

## Available Themes

| Theme | Description |
|-------|-------------|
| `default` | Clean light theme |
| `dark` | Dark variant |
| `dracula` | Dracula color scheme |
| `monokai` | Monokai color scheme |
| `nord` | Nord color scheme |
| `solarized` | Solarized color scheme |

## Customizing Components

Override component styles via theme:

```tsx
const myTheme = {
  ...defaultTheme,
  components: {
    Button: {
      background: '#6366f1',
      foreground: '#ffffff',
      hoverBackground: '#4f46e5',
    },
    Text: {
      muted: '#94a3b8',
    },
  },
};
```
