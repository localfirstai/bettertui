# Tree View

**Category:** Widgets  
**Level:** 2/5  
**Slug:** `tree-view`  
**Tags:** Tree, TreeNode, navigation

Expand/collapse a file-tree with keyboard navigation and selection.

## How to run

### From source (standalone)
```bash
bun examples/src/examples/widgets/tree-view.tsx
```

### Via launcher
```bash
node dist/index.mjs
# then select from the interactive menu
# or directly:
node dist/index.mjs tree-view
```

### Bundled standalone
```bash
node dist/examples/widgets/tree-view.mjs
```
