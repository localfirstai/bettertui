# Flex Layout

> Row/column flexbox, alignment, and gaps for responsive composition.

- **Category:** Layout
- **Level:** 2 / 5
- **Demonstrates:** Flex, alignItems, justifyContent, gap
- **Requires:** _None._

## What it shows

This example focuses on **Flex**. Read the source in
`src/examples/layout/flex-layout.tsx` — each example is small, self-contained, and easy to read.

## Run it

```bash
pnpm --filter @bettertui/examples build
node dist/index.mjs flex-layout
```

Or from the interactive browser:

```bash
pnpm --filter @bettertui/examples dev
```

## Key APIs

- `Flex`
- `alignItems`
- `justifyContent`
- `gap`
