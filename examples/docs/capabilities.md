# Terminal Capabilities

> Detect and display the current terminal's feature set via the native engine.

- **Category:** Terminal
- **Level:** 2 / 5
- **Demonstrates:** detectCapabilities, kittyKeyboard, trueColor, focusEvents
- **Requires:** `native engine`

## What it shows

This example focuses on **detectCapabilities**. Read the source in
`src/examples/terminal/capabilities.tsx` — each example is small, self-contained, and easy to read.

## Run it

```bash
pnpm --filter @bettertui/examples build
node dist/index.mjs capabilities
```

Or from the interactive browser:

```bash
pnpm --filter @bettertui/examples dev
```

## Key APIs

- `detectCapabilities`
- `kittyKeyboard`
- `trueColor`
- `focusEvents`
