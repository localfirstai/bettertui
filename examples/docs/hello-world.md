# Hello World

> The smallest possible BetterTUI screen rendered through React.

- **Category:** Core
- **Level:** 1 / 5
- **Demonstrates:** render, Box, Text, Provider
- **Requires:** _None._

## What it shows

This example focuses on **render**. Read the source in
`src/examples/core/hello-world.tsx` — each example is small, self-contained, and easy to read.

## Run it

```bash
pnpm --filter @bettertui/examples build
node dist/index.mjs hello-world
```

Or from the interactive browser:

```bash
pnpm --filter @bettertui/examples dev
```
