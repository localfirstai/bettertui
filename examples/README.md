# @bettertui/examples

Runnable example applications for BetterTUI. This is a single package (not a directory of per-example apps) where each example is a self-contained `.tsx` file in `src/` that exports a `meta` descriptor and renders through the React `render()` API.

## Examples

| Slug | Title | Category |
|------|-------|----------|
| `rendering-engine` | Rendering & Engine | rendering |
| `animation-basics` | Animation & Motion | animation |
| `live-metrics` | Live Metrics | performance |
| `performance-stress-test` | Performance Stress Test | performance |
| `scroll-area-basics` | Scroll Area | containers |
| `tabs-navigation` | Tabs & Accordion | navigation |
| `theming` | Theming | theming |
| `tree-view` | Tree View | data-display |

## Running

```bash
pnpm --filter @bettertui/examples build
node dist/index.mjs <slug>     # run one example
node dist/index.mjs --list     # list all examples
node dist/index.mjs            # interactive example browser
```

## Documentation

Per-example docs are generated by `scripts/generate-docs.mjs` (run after a build) into `docs/`. Each doc is derived from the example's `meta` export, so it always matches the committed source.

## Status

All examples are wired to the real `react-reconciler` host config. The React component functions are thin wrappers that emit element descriptors; the live native render loop is not yet connected, so examples exercise the API surface and reconciler rather than painting pixels to the terminal.

See the [examples documentation index](../docs/examples.md).
