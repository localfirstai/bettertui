# Examples

Runnable examples live in the **`@bettertui/examples`** package (`examples/`). Each example is a
small, self-contained module under `examples/src/examples/<category>/` that exports a `meta`
descriptor plus `run`/`destroy` contracts, and renders through the React `render()` API.

There are **15 examples**, grouped into 10 capability categories and launched through an
interactive browser that mirrors the experience of OpenTUI's example launcher.

## Running an example

```bash
pnpm --filter @bettertui/examples build
node dist/index.mjs <slug>
```

Or browse the catalogue:

```bash
node dist/index.mjs        # interactive menu (in a TTY)
node dist/index.mjs --list # compact catalogue
```

## Status

All 15 examples are wired to the real React reconciler and native render loop. Interactive
keyboard input uses an internal `KeyInput` manager (the public `useKeyboard` hook only fires on
DOM events, never in a TTY), so examples behave correctly in a terminal. Per-example docs are
generated by `examples/scripts/generate-docs.mjs` into `examples/docs/`.

## Other apps

`apps/website` is an Astro/Starlight docs + landing site (`@bettertui/website`). It does **not**
depend on the engine packages — it is the documentation portal, not a TUI demo. Benchmarking
lives in `packages/benchmark` (Vitest `bench` harness).

See the [Examples parity & gap report](../docs/EXAMPLES-PARITY.md).
