# AGENTS.md

## Architecture Documents

- Every document follows the pattern: Problem → Solution → Benefits → Trade-offs → Alternatives Considered → Future Evolution.
- Use diagrams (ASCII art) for system architecture, data flow, and module relationships.
- Document WHY each decision exists, not just WHAT the decision is.
- Cross-reference related documents (e.g., NodeModel.md references Protocol.md).
- The Roadmap.md tracks implementation phases — update it when architecture decisions change feasibility.
